Frontend Mentor Projects

This repository contains my solutions to challenges from Frontend Mentor.

The goal of this repository is to improve my front-end development skills by building real-world projects using modern web technologies.

🚀 What I’m Practicing

* Responsive Web Design
* HTML5 & Semantic Markup
* CSS3 (Flexbox, Grid)
* JavaScript (Basic to Intermediate)
* UI/UX Design Implementation

📁 Project Structure

Each project is organized in a separate folder and includes:

* Source code
* Assets (images, icons, etc.)
* Live preview (if available)

🎯 Purpose

I created this repository to:

* Strengthen my front-end development skills
* Build a consistent coding habit
* Create a strong portfolio for future opportunities

🌐 Platform

Challenges are taken from "Frontend Mentor" (https://www.frontendmentor.io), which provides real-world front-end projects to practice and improve skills.

📌 Note

These projects are for learning purposes. Feedback and suggestions are always welcome!

💭 A Little Story Behind This Repository

When I was in my first year of college and just starting to learn web development, I developed a strong interest in creating websites. I especially enjoyed working with HTML and CSS.

During that time, I discovered Frontend Mentor and started practicing by building some of its challenges.

The code in some of these projects might not be perfect. There may be mistakes, and I know there are many things I could have done better. But these projects hold a special place in my learning journey.

I still remember how happy and excited I felt when I managed to build something on my own, even if it wasn't perfect. Seeing my code turn into an actual webpage was a wonderful feeling.

These projects are a small reminder of where my journey started, how much I enjoyed learning, and how far I still want to go.

I'm sharing them here not because they are perfect, but because they are a part of my journey. ❤️
